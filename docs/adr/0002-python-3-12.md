# ADR 0002: Python 3.12 em todas as questões

- **Status:** Aceita
- **Data:** 2026-10-27

## Contexto

Há versões mais novas do Python (3.13 e 3.14), mas a questão 3 depende de FAISS e torch, bibliotecas com extensões nativas que costumam demorar a publicar wheels para versões novas. Sem wheel, a instalação tenta compilar do código-fonte e quebra na máquina do avaliador.

## Decisão

Python 3.12 em todas as questões, fixado no `.python-version` e em `requires-python = ">=3.12"`. O uv baixa essa versão sozinho se ela não estiver instalada.

## Alternativas consideradas

- **Versão mais nova só nas questões 1 e 2:** cada questão rodaria num Python diferente, e um padrão de código válido numa (sintaxe nova, por exemplo) poderia não valer na outra.

## Consequências

- O ruff e o mypy miram o 3.12 (`target-version` e `python_version`).
- Subir a versão exige conferir antes as wheels de FAISS e torch.
